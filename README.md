# PressTrigger v2.2

Windows 长按连点器：按住某个键，自动以你设定的速度连点该键本身，松开即停。

- 下载：[Releases](https://github.com/fbiii8/PressTrigger/releases/latest)
- 上游项目：https://github.com/Kin-L/PressTrigger

## 下载与安装

从 Releases 下载 `PressTrigger-v2.2-win-x64.zip`，解压后直接运行 `PressTrigger.exe`。

- 单文件程序，无安装步骤，资源（图标、提示音）已内嵌。
- 启动时申请管理员权限；被拒绝提权会明确提示，不会出现"点了没反应"。
- 配置写在 exe 同目录 `config.json`，删除该文件即恢复默认。

## 功能

1. **管理员权限启动**：清单直接声明 `requireasAdministrator`，双击即提权。
2. **多按键独立连点**：每个按键独立设置速度，可同时连点多个键；键盘与鼠标左/右/中键都支持。
3. **按住即连点、松开即停**：事件驱动（低层输入钩子），触发零延迟；间隔最低 1 ms，实测最快约 700–900 次/秒。
4. **每个按键可配两项参数**：
   - **连点间隔**：本次按下到下次按下的周期，范围 1–60000 ms。
   - **按下时长**：每次按键保持按下的时间，必须 ≤ 连点间隔；游戏通常需要 10–30 ms 才能稳定识别，太快会丢键。
5. **一键启用/禁用**：窗口顶部按钮或托盘菜单，切换时播放提示音。
6. **系统托盘**：最小化到托盘，双击图标恢复窗口，托盘提示显示当前状态。
7. **单实例锁**：命名互斥体，重复启动会提示。
8. **配置记忆**：自动保存到同目录 `config.json`。
9. **原子写盘**：先写临时文件再替换，异常退出不会损坏配置。

## 使用

1. 运行 `PressTrigger.exe`（会请求管理员权限）。
2. 点击「+ 添加按键」，在下拉框里选择按键。
3. 设置**连点间隔**与**按下时长**（单位毫秒）。
4. 长按该键开始连点；松开停止。
5. 列表内操作：
   - 点「启用」列的 ●/○ 单独开关某个键；
   - 双击「连点间隔」或「按下时长」单元格就地修改；
   - 点「操作」列的「删除」，或选中后按 Delete 键删除。

## 可设按键范围

- 数字：`0` – `9`；字母：`A` – `Z`
- 编辑键：`BACKSPACE`、`ENTER`、`SPACE`
- 导航键：方向键、`HOME`、`END`、`INSERT`、`DELETE`、`PAGE UP`、`PAGE DOWN`
- 符号：`-`、`=`、`[`、`]`、`\`、`;`、`'`、`,`、`.`、`/`、`` ` ``
- 鼠标：`LCLICK`（左键）、`RCLICK`（右键）、`MCLICK`（中键）

## 黑名单（不可设为连点键）

- 修饰键：`CTRL`、`SHIFT`、`ALT`、`WIN` 及左右版本
- 功能键：`F1` – `F16`
- 系统功能键：`TAB`、`ESC`、`CAPS LOCK`、`PAUSE`、`BREAK`、`NUM LOCK`、`SCROLL LOCK`、`PRINT SCREEN`

## 实现要点

- **真实输入隔离**：程序自身发出的按键带 `dwExtraInfo` 签名，低层钩子按 `LLKHF_INJECTED` 标志丢弃，引擎只看到真实物理输入。
- **不丢事件**：工作线程用条件变量 + 明确的按住状态同步，"按下"是状态而非一次性信号，任何时序下都不会丢失。
- **不卡死**：每轮连点结束都用真实键状态自纠一次；删除或禁用按键时正在进行的连点立即取消。
- **间隔准确**：Windows 默认时钟粒度 15.6 ms，直接 `time.sleep` 会把 10 ms 拉成 15.6 ms；本程序使用高分辨率可等待定时器 + `timeBeginPeriod(1)`，实测 10 ms 设定误差约 0.3 ms。
- **多键同按不互锁**：每个并发等待者独占一个定时器句柄（定时器池，用完归还），同时按住多个连点键时互不影响。
- **零空转**：空闲线程阻塞等待，没有轮询循环。

## 开发与打包

依赖安装：

```bash
pip install pystray Pillow playsound3 pyinstaller
```

`playsound3` 为可选：缺失时自动退回系统 `winsound`。

运行开发版（需要管理员权限才能装钩子）：

```bash
python main.py
```

打包为单文件 exe：

```bash
pyinstaller main.spec
```

产物位于 `dist/PressTrigger.exe`（无 CMD 黑窗，资源已内嵌，清单已声明需要管理员权限）。

## 注意事项

- 依赖低级键盘/鼠标钩子，**部分带反作弊的游戏或安全软件可能拦截**。若某个游戏里连点失效，先确认程序以管理员身份运行，并检查安全软件日志。
- 目标窗口若以更高权限运行（如某些游戏反作弊进程），`SendInput` 可能被 UIPI 阻止投递，此时连点无效属系统限制。
